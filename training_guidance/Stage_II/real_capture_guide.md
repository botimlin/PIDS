## 3. 相機系統安裝

### 相機位置

| 參數 | 數值 |
|------|------|
| 左相機 X | -15 mm |
| 右相機 X | +15 mm |
| Y 位置 | 0 (Chamber 前端內側) |
| Z 位置 | 場景中心高度 (~100mm) |

### 相機朝向

- 兩相機光軸平行
- 朝向 +Y 方向 (場景方向)
- 無俯仰、無旋轉

### 安裝要點

1. 使用剛性支架固定兩相機
2. 基線距離精確 30mm
3. 光軸平行度誤差 < 0.5°
4. 相機高度一致

| 亮度 | 8610 Lux @ 0.5m |

### 光源位置

| 參數 | 數值 |
|------|------|
| X | 0 (中心) |
| Y | -80 mm (相機後方) |
| Z | +120 mm (相機上方) |
| 傾斜角 | 55° (相對於水平面) |

### 安裝要點

1. 偏振片貼附於光源前方
2. 偏振片角度 0° (水平)
3. 確保光源均勻照射場景區域
4. 避免光源直射相機

## 8. 遮光處理

### 內壁處理

1. **消光塗層**：黑色消光噴漆
2. **絨布內襯**：黑色絨布貼附
3. **接縫密封**：黑色布膠帶

### 線材出口

```
┌─────────────────┐
│     Chamber     │
│                 │
│   ┌─────────┐   │
│   │ 出口    │←── 黑色橡膠密封圈
│   │ (線材) │   │
│   └─────────┘   │

```

### 存取開口

- 頂部或前方設計可開啟面板
- 開口處用黑色布簾遮光
- 拍攝時確保完全密封

### 遮光檢查

1. 關閉室內所有燈光
2. 關閉 Chamber
3. 等待 5 分鐘適應黑暗
4. 檢查是否有漏光

## 9. 校正與驗證

### 9.1 相機校正

1. **內參校正**：使用棋盤格標定板
2. **外參校正**：確定左右相機相對位置
3. **畸變校正**：修正鏡頭畸變

### 9.2 偏振片驗證

1. 旋轉光源偏振片，確認影像亮度變化
2. 交叉偏振 (90°) 時應最暗
3. 平行偏振 (0°) 時應最亮

### 9.3 幾何驗證

| 檢查項目 | 方法 | 標準 |
|----------|------|------|
| 基線距離 | 游標卡尺測量 | 30 ± 0.5 mm |
| 光軸平行 | 遠處目標對齊 | < 0.5° 誤差 |
| 光源角度 | 量角器/傾斜儀 | 55° ± 2° |

### 9.4 偏振對比度測試

```python
# 測試程序
1. 放置平面玻璃於場景中
2. 拍攝 I∥ 和 I⊥ 影像
3. 計算玻璃區域的對比度:
   contrast = (I∥ - I⊥) / (I∥ + I⊥)
4. 預期對比度 > 0.3 (在 55° 入射角)
```

## 10. 採集流程

### 10.1 準備工作

- [ ] Chamber 組裝完成
- [ ] 相機系統安裝並校正
- [ ] 光源安裝並調整角度
- [ ] 偏振片安裝正確
- [ ] 遮光檢查通過

### 10.2 場景設置

- [ ] 放置場景底座
- [ ] 放置背景
- [ ] 擺放透明物體 (Y = 528-695mm)
- [ ] 擺放背景傢俱
- [ ] 確認物體穩固

### 10.3 拍攝設置

| 參數 | 設定 |
|------|------|
| 解析度 | 640 × 480 |
| 曝光 | 自動或手動調整 |
| 白平衡 | 固定 (5600K) |
| 增益 | 最低 (減少雜訊) |

### 10.4 採集步驟

1. 關閉 Chamber，確保全黑
2. 開啟 LED 光源
3. 等待 30 秒穩定
4. 拍攝左相機影像 (I∥)
5. 拍攝右相機影像 (I⊥)
6. 記錄場景參數
7. 更換場景，重複步驟

### 10.5 數據管理
